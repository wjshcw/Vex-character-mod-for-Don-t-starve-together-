# 愁云使者 薇古斯（Vex the Gloomist）

> 饥荒联机版（Don't Starve Together）角色 Mod 版本：V0.1

[详细玩法介绍](./薇古斯Mod全面介绍.md)

---

## ✨ 角色特色

- **阴暗度（Gloom）**：独立于理智的第二资源条（0-200），受光照/湿度/队友影响；高于特定值影怪中立
- **暮气（Gloom Mist）**：所有奔跑/突进的生物都会缠绕暮气，薇古斯技能对暮气目标伤害翻倍
- **专属被动**：变质无害、瘴气免疫、猴子诅咒免疫、阵营克制（对月族增伤、受影魔减伤）
- **黑影（Shadow）**：专属成长护甲 —— 减伤 20% + 移速 10%，3 格升级槽装载 7 类 24 件模块（该部分灵感来源于小小格温mod）
- **四大技能**：寒心波云（穿透波）/ 愁煞（标记冲刺）/ 生人勿近（近身爆发）/ 溟濛渐染（延迟范围减速）
- **装备体系**：多用工具三等级（范围拆除+刨根）、专属武器三等级（真实伤害+弹射）、潜行三帽

## 📁 项目结构

```
modmain.lua            入口：注册、图集、字符串、补丁
main/                  技能逻辑（客户端按键/服务端RPC）、配方、容器、暮气被动
scripts/prefabs/       角色、黑影、模块、武器、帽子、技能特效等实体
scripts/components/    Gloom 组件
scripts/widgets/        阴暗度徽章 UI
anim/                  动画资源（zip：bank=build=动画名）
images/inventoryimages/ UI 图标图集
```
